# Nota investor presentation

The live presentation uses 9 native SVG slides per language, generated by
`render-slides.py` and embedded in `docs/pitch-deck.html`. French is canonical.
The HTML owns the shared brand shell and finite, replayable diagram animations;
SVG text, the accessible transcript and PDF content share the generated data.
The 18 PNGs remain static thumbnail and compatibility assets.

The story follows three product stages: urgent matching, an unproven 80% target
for reducing human time on defined repeatable preparation, and integration with
authorized electronic signing. It distinguishes observed market data, planning
assumptions, current demonstrations and commercial proof still to obtain.

`investor-sources.json` records primary sources, periods, units and scope. The
financial and local-market scenarios come from `docs/planning/business-plan-model.cjs`.
Québec CMA/province/Canada sales are nested counts; they must not be added or
represented as a count of eligible urgent acts. International notary counts are
reference pools, not validated paid seats or software revenue.

The viewer has one brand lockup in its global header. A second lockup is visible
inside the stage only during fullscreen, when the global header is absent. No
logo is baked into individual slides. Arrow keys, swipe, chapter buttons, replay,
animation pause and optional auto-advance are supported. Reduced motion shows
complete diagrams immediately. Sources and the readable transcript open on demand.

Regenerate from the repository root:

```sh
node docs/planning/business-plan-model.cjs
python3 docs/planning/render-business-plan.py
python3 docs/pitch-deck/render-slides.py --svg-out /tmp/nota-investor-slides
node docs/pitch-deck/rasterize-slides.mjs /tmp/nota-investor-slides
node docs/pitch-deck/build-pdf.mjs
python3 docs/pitch-deck/test-render-slides.py
node --test docs/pitch-deck/test-investor-deck.mjs
```

The PDF exporter reads the same SVG data, embeds the local Sora/Inter fonts and
preserves selectable text and primary-source hyperlinks. The resulting French
and English PDFs each contain 9 slides. No network font download or runtime
animation dependency is needed.

The business plan is a separate eight-chapter native slide experience, generated
by \`docs/planning/render-plan-slides.py\` as part of the plan renderer. Its
\`plan-deck.css\` and \`plan-deck.js\` are embedded in the standalone HTML. It
reuses Nota's SVG drawing vocabulary and animation sequences. Its own story
connects thesis, market scope, partnerships, preparation, signing, economics,
funding and execution. The English detailed plan and French companion remain
available under the relevant chapter. Printing includes all detail chapters.

The local-market controls alter qualification, capture and completion assumptions;
the cash control explores the twelve balances from the financing model. These
interactions do not change saved forecasts or claim validation of their assumptions.

The nine-slide editorial plan is documented in docs/planning/investor-editorial-plan.md. Both HTML surfaces embed docs/presentation-controls.js and .css, sharing labelled icon controls without a runtime dependency. The partner allocation is derived from domain referral rewards and does not double-count acquisition spending.
