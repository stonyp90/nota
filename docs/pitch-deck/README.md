The 32 PNGs here (`dark-slide-{1..16}.png` English, `dark-slide-fr-{1..16}.png` French, 1600×900) are the slides that `docs/pitch-deck.html` shows; they are drawn from the ADR 0048 dark-canvas tokens and the ADR 0050 type (Sora 800 titles, Inter body). The header lockup and the slide-1 hero are the decided brand (ADR 0048, design 02 · layout 16): the tile is read from `nota-mark.svg` and the O T A word from the `.brand-word` of `pitch-deck.html`, never redrawn; the deck page only knows the dark frames (`slideAsset()`), so there is no light variant.
Regenerate them with `python3 docs/pitch-deck/render-slides.py` — it needs ImageMagick (`magick`) plus the Sora and Inter families installed locally (fontconfig), and refuses to run when a face is missing because ImageMagick would silently substitute a generic sans. Without the faces installed, write the frames and rasterize them in the repo's Playwright Chromium (Google Fonts): `python3 docs/pitch-deck/render-slides.py --svg-out /tmp/slides && node docs/pitch-deck/rasterize-slides.mjs /tmp/slides` — the path that produced the committed PNGs.
The `.pptx` files under `docs/` are NOT the source of these slides: `render-slides.py` is, and the palette lives in its constants.
